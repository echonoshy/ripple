# viaim 下载知识

本文件只保留能直接回答下载问题的信息：该下载什么、适用什么产品、系统要求和下载链接。版本号、更新时间、安装包大小、海外可用性和企业部署方式不在当前知识库中，不要编造。

## 如何选择软件

- 智能体耳机 Pro / Air：下载 `viaim App`。
- iFLYBUDS 经典系列耳机：下载 `viaim 讯飞版`。
- 会议狗 / Kit 录制电脑会议：下载 `viaim 桌面端`。
- 只查看和编辑已上传云空间的记录：使用云空间网页或云空间客户端。
- iFLYPODS 系列音乐耳机：使用 `Sling`。

## viaim App

- 适用产品：智能体系列耳机。
- 主要能力：记录、思考与工作信息管理；连接耳机后可使用录音记录、翻译交流、viaim AI、转写内容编辑等能力。
- iOS 系统要求：iOS 15.0 及以上。
- Android 系统要求：Android 7.0 及以上。
- iOS 下载：`https://apps.apple.com/cn/app/viaim/id6759596579`
- Android 安装包：`https://viaim-web.iflybuds.com/pkg/VIAIM_inland_release.apk`

## viaim 讯飞版 / iFLYBUDS 经典系列 App

- 适用产品：iFLYBUDS 经典系列耳机。
- 主要能力：录音转文字、面对面实时翻译。
- 支持通话内容实时转文字，可区分说话人。
- 支持系统通话和常见网络通话，例如微信语音、钉钉语音、腾讯会议、QQ 语音、Skype、Teams、Zoom。
- 看视频、听音频时可提供实时转文字和翻译。
- iOS 系统要求：iOS 13.0 及以上。
- Android 系统要求：Android 8.0 及以上。
- iOS 下载：`https://apps.apple.com/cn/app/id1503159257`
- Android 安装包：`https://viaim-web.iflybuds.com/pkg/viaim.apk`
- 应用宝：`https://a.app.qq.com/o/simple.jsp?pkgname=tws.iflytek.headset&from=singlemessage`

## viaim 桌面端

- 主要能力：录制电脑上的通话和音频内容，并转成文字。
- 使用限制：录音功能需连接会议狗后使用。
- Windows 系统要求：Windows 10 及以上。
- macOS 系统要求：macOS 13.0 及以上。
- macOS 13.0 以下用户：需要联系客服获取下载安装包；暂不支持 macOS 10.12 及以下版本。
- Windows 下载：
  - `https://viaim-web.iflybuds.com/pkg/iFLYBUDSKit32.exe`
  - `https://viaim-web.iflybuds.com/pkg/viaim_setup.zip`
- macOS 下载：`https://viaim-web.iflybuds.com/pkg/viaimmac.zip`

## 回答口径

- 用户问“下载哪个 App”时，先按产品系列判断：智能体系列用 viaim App，经典 iFLYBUDS 系列用 viaim 讯飞版，电脑会议录制用 viaim 桌面端。
- 用户问 viaim App 下载时，给 iOS App Store、Android APK 和系统要求。
- 用户问 iFLYBUDS 经典 App 下载时，说明适用经典系列耳机，并给 iOS 13.0+ / Android 8.0+ 要求。
- 用户问电脑端录音时，说明 viaim 桌面端可录制电脑通话和音频并转文字，但录音功能需连接会议狗。
- 用户问 macOS 低版本时，回答：macOS 13.0 以下用户需联系客服获取安装包，暂不支持 macOS 10.12 及以下版本。
