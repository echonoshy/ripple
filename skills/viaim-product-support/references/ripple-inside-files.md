## Page Meaning

Files is the browser for the current user's long-lived Ripple workspace. It is not a temporary session upload tray. Files here can be used by chat, generated by Codex, downloaded by the user, previewed, edited when supported, renamed, moved, copied, or deleted.

`FilesPage.tsx` wraps `WorkspaceExplorer` with `data-ripple-files-page="finder-stage"`.

## Common Areas

### Toolbar

Visible clues:

- Search icon/input.
- Select files toggle.
- Upload button.
- More file actions.
- Refresh.
- Breadcrumb/current path.

Behavior:

- Search calls `searchWorkspaceFiles`.
- Refresh reloads the current listing through `fetchWorkspaceListing`.
- Upload calls `uploadWorkspaceFiles`.
- More actions can expose create/paste/selection actions depending on current state.
- Breadcrumb buttons navigate folders. Navigation is low-risk.

### File List

Visible clues:

- `data-ripple-workspace-file-list="browser"`.
- Folder/file rows, checkbox/select affordances, row action menu.
- Parent folder and workspace root controls.

Behavior:

- Opening a folder changes the current path.
- Opening a file loads a preview via `fetchWorkspaceFilePreview` or a document preview.
- Row more-actions can lead to rename, download, copy/move, delete, or other entry actions depending on file type and selection.

### Preview Panel

Visible clues:

- `data-ripple-workspace-preview="preview"`.
- File title/path, metadata, edit/open fullscreen/collapse controls.

Behavior:

- Text previews use `fetchWorkspaceFilePreview`.
- Office/PDF-like document previews can use `fetchWorkspaceDocumentPreview`.
- Download uses `downloadWorkspaceFile`.
- Edit/save uses `saveWorkspaceFile` when the preview supports editing and is not truncated.
- Fullscreen preview changes the view only.

## Actions And Effects

| UI action | API/function | Effect | Risk |
| --- | --- | --- | --- |
| Browse/open folder | `fetchWorkspaceListing` | Changes current visible path | Low |
| Search | `searchWorkspaceFiles` | Shows matching entries | Low |
| Preview/open file | `fetchWorkspaceFilePreview`, `fetchWorkspaceDocumentPreview` | Reads file content or preview | Low, unless file contains sensitive content |
| Upload | `uploadWorkspaceFiles` | Adds files to current workspace folder | State-changing; overwrite conflicts can replace content |
| Download | `downloadWorkspaceFile` | Downloads a copy to the client | Low but may expose data outside app |
| Rename | `renameWorkspaceEntry` | Changes file/folder name | State-changing |
| Create file/folder | `createWorkspaceEntry` | Adds a new entry | State-changing |
| Copy/move/paste | `pasteWorkspaceEntry` | Copies or moves an entry to destination folder | State-changing; move changes original location |
| Save edit | `saveWorkspaceFile` | Writes new file content | State-changing; conflict can occur if file changed on disk |
| Delete | `deleteWorkspaceEntry` | Removes file/folder from workspace | Destructive |

## How To Answer

If the screenshot shows a file action menu, explain only the action that is visible or the user named. Mention path and selected entry only if visible. For destructive actions, say it changes the workspace and should be confirmed intentionally.
