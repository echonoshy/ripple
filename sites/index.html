Product

A compact workspace for real agent tasks.

Ripple is not another prompt box. It gives each user a persistent place where agents can read and write files, resume sessions, request connector authorization, generate outputs, and expose progress without moving server logic into the client.

Built around the user journey

Users start from sessions, continue into task progress, review generated files, and return later without losing the workspace. The same model works across mobile, desktop, and web clients.

Workspace

Files, connectors, automations, and settings live together.

Files

Users can inspect the workspace and generated artifacts without leaving the app.

Connectors

External account access is explicit, visible, and scoped to the current user.

Automations

Scheduled work uses the same sessions, permissions, and execution boundary.

Settings

Client configuration, sandbox status, and usage stay close to the product surface.

Platform

Product surface in front, Rust control plane behind it.

Ripple keeps backend responsibilities on the server: user isolation, session state, connector auth, approvals, schedules, skill manifests, and the OpenAI-compatible `/v1` API. Codex app-server remains the execution plane.

01

Control plane

Rust server manages users, workspaces, sessions, runs, quotas, and API boundaries.

02

Execution plane

Server-side Codex app-server performs the actual agent work under managed permissions.

03

Client surface

Web, Tauri desktop, iOS, and Android clients call Ripple Server instead of owning backend logic.
