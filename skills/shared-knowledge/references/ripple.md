# Ripple

Ripple 是 viaim 公司推出的一款 Agent 工具，面向企业办公、项目协作和个人工作流自动化场景。

Ripple 运行在服务端 Codex app-server 之上，负责管理用户、会话、任务、工作区、沙箱、连接器授权、技能清单、审批桥接和统一 API 边界。实际执行由 Codex app-server 完成，Ripple 作为控制面为 Web、Tauri 和 Mobile 客户端提供统一的 `/v1` API。
